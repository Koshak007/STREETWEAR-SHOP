## О проекте 
**STREETWEAR SHOP** - концепт интернет-магазина одежды, созданный для любителей современного уличного стиля. Здесь собраны актуальные вещи в стиле streetwear, вдохновлённые современной модой, музыкой и городской культурой.

Мы подбираем вещи, которые легко сочетать между собой и использовать для создания собственного уникального образа.

Основная идея проекта - сделать покупку одежды простой, удобной и быстрой.

## Цель проекта 
Главная задача проекта - создать удобный интерфейс магазина, в котором пользователь сможет:
1. Найти нужную категорию одежды.
2. Посмотреть информацию о товаре.
3. Выбрать размер.
4. Добавить товар в корзину.
5. Оформить заказ.

## Возможности 
- Каталог - возможность посмотреть все доступные товары
- Карточки товаров - фотография, описание и цена 
- Фильтрация - поиск товаров по категориям 
- Размеры и цвет - подбор подходящего размера и цвета 
- Корзина - добавление и удаление товаров 
- Личный кабинет - просмотр профиля и заказов 
- Онлайн-оплата - оплата заказа на сайте
